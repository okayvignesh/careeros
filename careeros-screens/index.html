Each screen is a single self-contained HTML file at 1440×900: all CSS, JavaScript, the component bundle and the Inter subset are inlined, so it opens with no network access and no folder to keep together. Hover states, the entrance animation, dropdowns, modals, toasts and tooltips are live in the file. Seven enrichment screens from the 67-screen inventory are deliberately deferred and are not in this export.
